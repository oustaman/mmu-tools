Help

The Room Finder lists every room at Castlegate University, a university that does not exist, made up for teaching. The opening screen is an A to Z index of the estate's buildings; choose one to see its floors, plans and rooms.

Searching

Type a room number (GM 1.04), a building code (GM), a room name, a timetable code or a department. Results are ranked by how well they match: an exact building code or room number comes first.

Adding a space finishes a word: GM  with a trailing space matches only whole words.

Keyboard

  • / focus the search box
  • Tab move between controls; Enter or Space activates rooms, buildings and floors
  • Esc closes a profile, viewer or dialog
  • In the floor plan viewer: + and − zoom, 0 fits the plan to the screen

Abbreviations

  • SM Space Management, the university's own room figures
  • TT timetable
  • EMS Estates Management Statistics space code
  • FM Facilities Management

Display

The moon button switches between light and dark colour schemes. Text can be enlarged with your browser's zoom, and the layout adapts down to phone width. Animation is switched off when your system asks for reduced motion.

Every building, room and address here is invented. The addresses end in .example, which cannot reach anyone.
